# 趣味を紹介するページ

課題ID: WEB-002 / 難易度: L2 / 目安: 45分 / 通常の支援上限: H3

## 目的
意味のあるHTMLと外部CSSを自分で組み合わせる。

## 前提知識
[HTML/CSS教材](../../../curriculum/01_web_basics/01-html-css.md)

## 課題
趣味の紹介ページを作る。見出し、2段落、3項目の一覧、参考サイトへのリンクを含める。CSSで余白と読みやすい行間を調整する。

提出先：exercises/web/submissions/WEB-002/attempt-01/。
回答はanswer.md、実行・観察はevidence.md、必要なHTML/CSS/JSはsite/に保存します。
再提出はattempt-02以降へ保存します。本人が作成し、AIの文章を自分の説明として転記しません。

## 制約
外部CSSを1つ使う。見た目のために空白文字を並べない。実名や住所は不要。

## ヒント
読む前に自分の予想と試行を書き、開いた段階を記録します。

## 完了条件
必要な内容があり、CSSが読み込まれる。狭い画面でも横にはみ出さずリンクへキーボードで移動できる。
