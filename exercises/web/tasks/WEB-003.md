# 200と404を観察して切り分ける

課題ID: WEB-003 / 難易度: L3 / 目安: 40分 / 通常の支援上限: H3

## 目的
ファイル・HTTP・ブラウザーの観察を組み合わせる。

## 前提知識
[HTTP教材](../../../curriculum/01_web_basics/02-http.md)、HTML、Python 3の起動確認

## 課題
siteに自作index.htmlを置き、HTTP教材の手順で127.0.0.1に配信する。存在するページと存在しないページを読み、Networkでメソッド、URL、ステータス、Content-Typeを記録する。サーバー停止後の結果も予測して観察する。

提出先：exercises/web/submissions/WEB-003/attempt-01/。
回答はanswer.md、実行・観察はevidence.md、必要なHTML/CSS/JSはsite/に保存します。
再提出はattempt-02以降へ保存します。本人が作成し、AIの文章を自分の説明として転記しません。

## 制約
学習用siteだけを配信する。公開しない。観察ログに秘密情報を含めない。コマンドは自分の環境に合わせる。

実行した環境、手順、期待、実際、AI支援の最大レベルをevidence.mdに記録します。
