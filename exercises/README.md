# 演習の入口

最初は[ORI-001](web/tasks/ORI-001.md)からCoachと進めます。全課題を一度に実施する必要はありません。

| 課題 | 難易度 | 実施時期 |
| --- | --- | --- |
| [ORI-001 支援の頼み方](web/tasks/ORI-001.md) | L1 | 学習開始 |
| [ORI-002 HTMLを開く](web/tasks/ORI-002.md) | L2 | 環境確認後 |
| [WEB-001 通信の予測](web/tasks/WEB-001.md) | L1 | HTTP教材 |
| [WEB-002 紹介ページ](web/tasks/WEB-002.md) | L2 | HTML/CSS教材 |
| [WEB-003 通信の観察](web/tasks/WEB-003.md) | L3 | HTTP教材・Python起動後 |
| [WEB-004 フォーム](web/tasks/WEB-004.md) | L3 | フォーム教材 |
| [WEB-005 読書メモ](web/tasks/WEB-005.md) | L4 | JavaScript・DOM学習後 |
| [WEB-006 要件から作る](web/tasks/WEB-006.md) | L5 | 小アプリ・Git・テスト学習後 |

tasksは課題、submissionsは学習者の回答です。各課題指定の場所へ本人が保存します。
提出には予想、実装、実行方法、期待結果、実際、支援量を含めます。
課題難易度L1〜L5とAI支援H1〜H5を分け、参照したヒントを記録します。
再提出はattempt-02などを追加し、失敗した試行を消しません。
他分野のtasksは教材の進行に合わせexercise-designerが追加します。
