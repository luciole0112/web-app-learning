# 環境を確認し、最初のHTMLを開く

教材ID: LESSON-ORI-002 / 目安30〜60分 / 到達条件: 保存場所を把握し、自分のHTMLをブラウザーで確認できる。

## この教材で学ぶこと
VS Codeで学習フォルダーを開くこと、ファイルを保存すること、結果をブラウザーで見ることです。
最初から全技術をインストールする必要はありません。

## 前提知識
[学習方法](01-learning-method.md)。ブラウザーとファイル操作が使えること。

## なぜ必要なのか
「どのファイルを編集しているか」「どこでコマンドを実行しているか」が分からないと、
正しいコードでも動かないことがあります。まず場所と結果の関係を確かめます。

## 基礎概念
エディターはファイルを書く道具、ブラウザーはHTMLなどを表示する道具です。
ターミナルは文字で操作を指示する場所です。作業フォルダーによって操作対象が変わります。
Gitは変更を記録する道具、GitHubはその記録を共有するサービスです。

## 具体例
VS Codeで学習ルートを開いたら、左側にREADME.mdと.githubが見えることを確認します。
outputsなど親フォルダーを開いていたら、web-app-learningを開き直します。
Copilotを使う設定は[開始ガイド](../../docs/getting-started.md)にまとめています。

## コード例
読むための最小HTMLです。タイトルはタブ、見出しはページに表示されます。
```html
<!doctype html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <title>観察用の例</title>
</head>
<body>
  <h1>こんにちは</h1>
  <p>ファイルを変更すると表示も変わります。</p>
</body>
</html>
```

## 実践
1. exercises/web/submissions/ORI-002/attempt-01を自分で作ります。
2. 自分の題材でindex.htmlを書きます。拡張子が.html.txtになっていないか確認します。
3. 保存して、ファイルをブラウザーで開きます。まだHTTPサーバーは不要です。
4. 見出しを書き換え、保存してブラウザーを再読み込みします。
5. 変わらなければ、開いているパス、保存状態、編集したファイル名を確認します。
6. evidence.mdに手順と結果を記録します。

今日必要なのはVS Code、ブラウザー、Copilotを使う場合のアカウントです。
GitはPhase 2、Node.jsはJavaScript/React、PythonはHTTP観察やFastAPI、DBとDockerは該当段階で導入します。
導入時は公式サイトの対応版を確認し、使用バージョンを記録します。
Pythonが使える場合の確認はターミナルでpython --version。Windowsで使えなければpy --versionも確認します。
どちらも失敗したら、エラーをCoachに伝えてください。成功したことにしないでください。

## 理解度チェック
- 保存とブラウザーの再読み込みは、なぜ両方必要ですか。
- ターミナルで操作する場所はどう確認しますか。
- ローカルファイルを開くことと、HTTPで取得することは同じでしょうか。

## よくある間違い
別の同名ファイルを開く、保存せず再読み込みする、拡張子を間違えることです。
環境の問題とHTMLの問題を分けて調べます。

## 実務ではどう使うか
チームで起動手順と必要なバージョンをREADMEに残し、別の人でも再現できるようにします。

## まとめ
編集→保存→表示→変更確認ができれば最初の一歩は完了です。
Copilot設定が読めたことは[手動確認](../../docs/acceptance-checklist.md)で別に確認します。
