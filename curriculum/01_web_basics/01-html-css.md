# HTMLとCSSで意味と見た目を分ける

教材ID: LESSON-WEB-001 / 目安45分 / 到達条件: 意味のあるHTMLと外部CSSで小さなページを作れる。

## この教材で学ぶこと
HTMLで内容の役割を表し、CSSで表示を調整します。見た目だけでなく読みやすさも確認します。

## 前提知識
[環境とHTML](../00_orientation/02-setup.md)。保存と再読み込みができること。

## なぜ必要なのか
見出しを大きな文字にするだけでは、内容の構造は伝わりません。
HTMLの意味を正しく表すと、人にもブラウザーにも内容の関係を伝えられます。

## 基礎概念
要素はh1やpなど、内容の役割を示す部品です。属性はlangやclassなどの追加情報です。
CSSのセレクターは適用先を選び、宣言は色や余白などの値を指定します。
classは複数の要素をまとめて選ぶ名前です。idはページ内で一意にします。
リンクは移動、ボタンは操作に使います。

## 具体例
お店の営業時間なら、店名が見出し、営業時間が段落、営業日が一覧になります。
何でもdivにする前に、その情報の役割を考えます。

## コード例
HTMLの一部分です。完全なHTMLのheadに外部CSSへのlinkを追加します。
```html
<link rel="stylesheet" href="style.css">
<main>
  <h1>山の喫茶店</h1>
  <p class="notice">毎週水曜日はお休みです。</p>
</main>
```
同じ場所のstyle.cssに書く例です。
```css
body { font-family: sans-serif; line-height: 1.6; }
.notice { padding: 1rem; border-left: 4px solid #245a38; }
```
.noticeが選ぶ要素を説明し、枠線の色だけ変えたら何が変わるか予測します。

## 実践
1. 教材例とは別の題材を選び、ページの内容を箇条書きにします。
2. 見出し、段落、一覧、リンクに分類します。
3. HTMLを作り、次に外部CSSを追加します。
4. ブラウザーの幅を狭め、文字が重ならないか観察します。
5. 開発者ツールのElements/要素で構造と適用されたCSSを確認します。
6. CSSの参照先を一時的に間違えると何が起きるか予測し、観察して元に戻します。

## 理解度チェック
- h1を使う理由を文字サイズ以外で説明できますか。
- CSSが読み込まれない時、どこから確認しますか。
- リンクとボタンはどう使い分けますか。

## よくある間違い
CSSファイル名の違い、classの綴り違い、固定幅で小さな画面にはみ出すことです。
色だけで情報を伝えると区別しにくい人がいるため、文言や形も使います。

## 実務ではどう使うか
Reactでも出力されるのはHTMLです。部品化する前に意味と操作を設計します。

## まとめ
HTMLは内容の意味、CSSは表示を担当します。問題は構造と見た目に分けて調べます。
