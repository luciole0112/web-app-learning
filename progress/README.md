# 進捗の入口

| --- | --- |
| [learner-profile](learner-profile.md) | 目標、経験、環境、時間 |

初期状態は未診断です。0は未評価の仮値で、能力を判定した値ではありません。
[初回診断](../docs/assessment/initial-assessment.md)をCoachと実施します。
更新はlearning-coachだけが[手順](../docs/session-protocol.md)に従って行います。
学習者は実装と証拠をexercises/projectsへ保存し、Coachがその参照を評価に残します。
